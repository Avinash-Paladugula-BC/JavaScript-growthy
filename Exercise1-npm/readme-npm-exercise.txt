Create a folder named Exercise1-npm
 
To initialize the project I used the command: npm init -y
This will initialize npm project and package.json file is created

Used the command npm install lodash which will install the lodash package and add to project dependencies and packgae-lock.json is created.

To write the code I created the file: index.js file and written the code where I have to import the lodash
To run the code the command used is: node file_name

For accrount creation and login: 
I created the account from the link
From the terminal I ran the command: npm login which asked me to press enter for the verification by redirecting to browser
After verification  I  ran the command npm whoami which displayed my username.
